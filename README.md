# Drive Stream Pro

بناء منصة لتشغيل فيديو من خلال رابط مرتبط ملف على كوكل درايف وتتكون لقاطات من الافلام الموجودة على الرابط وتكون لها تفاعلات مع المستخدم حسب الفيديوهات وكذلك مدة المشاهدة ونوع المشاهدة والتكرار واللقطات والاهتمامات 1- تحسين مشغل الفيديو ليشمل كل صيغ الفيديوهات العالم مثل VCL K-Lite CODE 2-بصيغة paw 3- تحسين التشغيل ليتناسب مع ابعاد جهاز المستخدم 4-صنع شعار وايقونة تتناسب مع المحتوى تتغير بشكل تلقائ ...


بدون تسجيل دخول يتم الاستيراد فقط من خلال رابط واحد فقط دفعة واحدة ويتم مزامنة بشكل تلقائي كل 24 ساعه او يدوي
